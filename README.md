# 个人主页

这是我的个人主页项目（蓝喜阳）。第一版原型已完成；第二版（V2）已定稿；**第三版（V3）在首页新增「意见反馈」功能，当前在线版本即第三版**。

> **线上地址（GitHub Pages）**：<https://qilumanman.github.io/>　｜　源码仓库：<https://github.com/Qilumanman/Qilumanman.github.io>

V2 的视觉共经历三次整页迭代，每次都留档：

1. **深色科技风**（`版本存档/V2-深色科技风/`）—— 最初的暗色实验室质感。
2. **浅色新风**（`版本存档/V2-浅色新风/`）—— 去掉 Tailwind 外链，整页改为浅蓝白。
3. **黄白杂志风（当前在线版本，第二版最终稿）**（`版本存档/V2-黄白杂志风/`）—— 按参考长图重做视觉：
   **奶油米白纸面 + 琥珀金主色**，标题换衬线体（编辑杂志感），页面底纹加一层极淡的稿纸网格（轻科技学术感）。
   原有蓝色 / 青色 / 紫色元素全部替换为暖色系，页面结构、文案与全部交互（围棋落子、数字分身问答、邮箱复制）完全沿用。
   随后又撤下了「身份」卡里的两张双校联合培养配图，并把该卡片改为撑满整行、与右侧信息卡齐平。
   定稿清扫：删掉首页遗留的休眠灯箱死代码（结构 / 样式 / 脚本三处），并把 `pages/` 三个二级页（关于 / 博客 / 作品）
   统一成同一套黄白杂志风皮肤（同一导航、同一纸面卡片、同一页脚），版式与文案保持原样。

**第三版（V3 —— 当前在线版本）**：视觉沿用第二版的黄白杂志风，在首页新增第 05 节「意见反馈」。

- 访客要填 **5 项**：① 名字或昵称（可留空，默认匿名访客）② 与主页主人的关系 ③ 本条反馈针对的设备 ④ 反馈内容 ⑤ 提交时间（自动生成）。
- 隐私承诺（写在同一区的隐私卡里）：反馈**不公开**、他人看不到也删不掉；填了联系方式才会回复；可以完全匿名。
- **前端只写不读**：`GET /api/feedback` 一律返回 405，公开接口永不返回联系方式；只有作者本地后台能看到全部字段。
- 数据通道双模式（`js/feedback-config.js` 里的 `mode`）：**线上发布用 `supabase`（当前启用）** —— 走 Supabase 的 `anon public` 公开密钥，RLS **只允许 INSERT、禁止 SELECT**，匿名读不出来；`local` = 本地 `server.py` 备用（离线演示 / 自测）。
- **线上反馈在哪里看**：Supabase 控制台 → Table Editor → `public.feedback`（也可用 SQL Editor 查询或导出 CSV）。线上站点是纯静态托管，所以**没有**部署在线的作者后台页面。
- 本地备用后台 `http://127.0.0.1:8000/admin?token=<令牌>`：统计卡 + 5 列表格 + 标记已读 / 已解决 + 删除单条 + 导出 CSV；它读的是本地 SQLite，**看不到线上反馈**。令牌存在 `db/admin_token.txt`，**不提交仓库**。

目录分为两大块：

1. **材料分类目录** —— 用于存放前期准备阶段收集、编写的各类资料与素材。
2. **网页骨架** —— 第一版正式页面（`index.html` / `css/main.css` / `js/main.js`），含数字分身聊天区。

## 本地运行（含反馈后台）

```powershell
python server.py --port 8000        # 启动本地服务（网页 + 反馈接口）
# 访客页：  http://127.0.0.1:8000/
# 管理后台：http://127.0.0.1:8000/admin?token=<db/admin_token.txt 里的令牌>
# 导出 CSV：http://127.0.0.1:8000/export?token=<令牌>
```

- 直接双击 `index.html` 也能看页面，但**反馈提交需要上面的服务**（默认 `mode: "local"`）。
- 想走线上 Supabase：把 `db/supabase_feedback.sql` 在 Supabase 的 **SQL Editor** 执行建表，再把 `js/feedback-config.js` 的 `mode` 改成 `"supabase"` 并填 `supabaseUrl` 与 `anon public` key。
- ⚠️ **截图 / 预览前先确认服务在跑**：服务没起时浏览器只会给「无法访问此页面 · 127.0.0.1 拒绝连接」，看起来很像页面渲染坏了。

## 怎么用

- 前期：把收集的资料放进**材料分类目录**对应的文件夹。
- 想把 Word / PDF / 网页 / 图片转成 Markdown？放到 `04-文档原件/`，之后可统一转成 Markdown 存到 `05-Markdown内容/`。
- 未来开发时，再使用 `网页骨架` 部分的代码。

## 文件自动转 Markdown

DeepWorks 自带转换工具（`dw-markitdown`），支持 Word、PDF、PPT、Excel、网页、图片等转成 Markdown。你后续把材料放入对应文件夹后，我可以帮你批量转成 Markdown，存到 `05-Markdown内容/`。
